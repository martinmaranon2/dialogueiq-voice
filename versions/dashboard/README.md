# DialogueIQ — Wealth Advisor Dashboard

A shared prototype built for the UBS challenge at the Swiss AI Weeks Hackathon 2025. DialogueIQ presents client information, conversations, and suggested advisor actions in a single dashboard.

The repository includes both a Supabase-backed frontend and experimental transcript-analysis agents. The current dashboard's chat responses are generated by local preset logic; the agent pipeline is not wired into a server API route in this version.

## How it works

1. Next.js routes render the dashboard and alternate chat/dashboard views.
2. `hooks/useClients.ts`, `useConversations.ts`, and `useActions.ts` query Supabase through `lib/supabase.ts`.
3. `useClientSelection.ts` manages client selection and filtering.
4. `useAIChat.ts` handles chat state and produces preset responses from client context.
5. Separately, `lib/agents/orchestrator.ts` defines preprocessing → intent/entity extraction → classification → validation → finalization using the OpenAI wrapper in `lib/llm/`.

The presence of the pipeline source does not mean the dashboard executes it or persists its output automatically.

## Tech stack

Next.js 14 App Router, React 18, TypeScript, Tailwind CSS 3, Radix UI, Supabase/PostgreSQL, Recharts/ApexCharts, and Framer Motion. Experimental model code references OpenAI and dotenv.

## Setup

Use Node.js and npm; the audit used Node.js 24.

```sh
git clone https://github.com/martinmaranon2/zurich-ai-hack-25.git
cd zurich-ai-hack-25
npm ci --ignore-scripts
```

Create an ignored `.env.local` in the project root:

```dotenv
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```

The browser reads these variables. Use a public anon key, never a service-role credential, and configure database access policies appropriately.

**Database prerequisite:** the existing [Supabase setup guide](SUPABASE_SETUP.md) describes the expected schema, but its referenced `supabase-schema.sql` is absent from this repository. Obtain the compatible schema and sample records from the project maintainers before expecting a populated dashboard. Do not substitute a schema from a related repository without checking the hook queries and field names.

```sh
npm run dev
```

Open the local URL printed by Next.js, normally `http://localhost:3000`. Without a compatible database, the frontend may show loading, empty, or error states.

## Build and checks

```sh
npm run build
npm run start
./node_modules/.bin/tsc --noEmit
```

Audit on 2026-10-22: `npm ci --ignore-scripts`, production build, and production homepage HTTP 200 passed with placeholder Supabase values. Live database behavior was not tested. The build configuration skips linting and type validation; a separate TypeScript check reported 25 existing diagnostics.

## Experimental pipeline status

- The manifest does not declare the `openai` and `dotenv` imports used by `lib/llm/index.ts`. The pipeline is not independently ready to run from a clean dependency install.
- Its prompt loader reads from disk. The default `prompts/classifier.txt` path does not match the checked-in `lib/prompts/classifier.txt`; a standalone caller would need to pass the correct path.
- The model wrapper reads `OPENAI_API_KEY` and optional `OPENAI_MODEL` from a root `.env` file. These are unnecessary for the current preset dashboard chat.
- There is no package `test` script. Agent evaluation files refer to external datasets and should not be presented as a self-contained automated test suite.
